# EC280 Replication Project
Replication Project for UCSD's ECON280 Computation course for Fall Quarter 2025.

A Replication Repository for "When the Levee Breaks: Black Migration and Economic Development in the American South" by Richard Hornbeck and Suresh Naidu, published in the American Economic Review in 2014. It is done in STATA.

To replicate the project, simply follow the readme.txt follow in the "Code" folder, which explains that one must run, in order, "Generate_flood.do" -> "flood_preanalysis.do" -> "flood_analysis.do".

In the "Assignment 4" folder, I include an extension project that generates a table that is put into the "Code" folder. The folder itself contains my own extension, which is analyzing the robustness from the use lags of one of the main results of the table.

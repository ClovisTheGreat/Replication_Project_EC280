Description of Replication files for Hornbeck and Naidu, "When the Levee Breaks...."

There are three .do files, "Generate_Data\Generate_flood.do", "Preanalysis\flood_preanalysis.do" and "Analysis\flood_analysis.do" that should be run in that order. The first file, when run in the "Generate Data" folder, will:  (1) assemble the data, (2) do the border adjustments to 1900 boundaries, and (3) produce a file called flood_base1900.dta. This .dta file should be moved into the Analysis folder. The second file, "flood_preanalysis.do", takes flood_base1900.dta and produces three "preanalysis" .dta files, with a variety of variables generated and prepared for analysis. These files are then used by "flood_analysis.do" to generate all the tables and figures shown and discussed in the paper. The .do file will write tables to the Analysis/Tables directory and figures to the Analysis/Figures directory. Pathnames may have to be changed on other operating systems.

In addition, flood_analysis.do generates a number of tables not in the paper, as robustness checks and other items discussed in the paper. These include looking at additional outcomes: crop output/population, crop output/rural population, landvalues and landvalues/acre, as well as cotton and corn yields. All these can be found in AdditionalTable.csv.  Pre-differences for the other Southern river sample can be found in "Table6_predifferences.csv".  A number of robustness checks, controlling for manufacturing, tenancy, as well as propensity scores, can be found in RefTables 1 through 3. Robustness to alternative measures of flood intensity can be found in RobustnessMeasures2, and RobustnessMeasures3 Tables1-3. The plantation interaction results can be found in Robustness_PlantationInteraction. RefTable4, provides estimates for different tractor variables, and are used for the calculations of relative increases of tractors.  The end of the file (flood_analysis.do) estimates Conley standard errors for various outcomes.
